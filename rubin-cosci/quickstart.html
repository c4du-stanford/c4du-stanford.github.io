Quickstart

Install

Open the install page, https://c4du-stanford.github.io/rubin-cosci/install/, and sign in to GitHub when asked. If it shows 404, ask the person who invited you to add your GitHub account.

On a Mac

  1. Click Download for Mac. A folder called Install CoSci opens.
  2. Open Terminal: press ⌘-Space, type Terminal, press Return.
  3. Paste this line and press Return. The CoSci setup window opens; leave Terminal open until it is done.
bash "/Volumes/Install CoSci/cosci-install.sh"

On the Rubin Science Platform or Linux

  1. Click Download for the RSP or Linux to get cosci-install.sh.
  2. On the Rubin Science Platform, drag the file into JupyterLab's file browser, then open a Terminal from the Launcher.
  3. Run bash ~/cosci-install.sh (on Linux: bash ~/Downloads/cosci-install.sh).
  4. Answer the questions in the terminal. Press Enter to take each default.

The setup window

One page at a time:

  • This Mac: what CoSci found. Nothing changes yet.
  • Coding agent: Claude Code, Codex, or None. You sign in with your own account. None is fine: you can add one later.
  • GitHub: needed for shared labs. Get my code shows a one-time code; paste it on github.com.
  • Labs, your private labs: only you read them. One on this Mac is already added, which is all most people need. Labs on your GitHub account are listed with Add, or type one as owner/name, or start a new one on GitHub.
  • Labs, shared labs: labs you were invited to are listed. Click Accept and add or Add. Or type a lab's name, like owner/name, and click Check and add.
  • Settings: background learning, and whether to type cosci in Terminal.
  • Review, then Install CoSci, then Open CoSci.

The Guide button at the bottom left opens these guides.

First things in the CoSci window

  • Open a lab. Click its name in the sidebar to see its threads.
  • Start a thread. Click New thread under a lab and give it a name.
  • Talk or post. Type in the box and press Return. With an agent, it answers and the exchange is recorded. With no agent, your words go in as a note.
  • Add a plot or a doc. Click the paperclip, pick the file, write a caption, send.
  • Read the guide. Click Guide at any time.
